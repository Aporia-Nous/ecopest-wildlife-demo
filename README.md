# ecoPest Wildlife Management — AI Call Intake Demo

Live demonstration of an AI phone receptionist and intake agent built for wildlife removal and emergency pest control services.

## Overview
This demo showcases:
- 24/7 automated emergency call triage and dispatch qualification.
- Instant animal species identification and location risk assessment.
- Direct appointment scheduling and call forwarding workflows.

## Files
- index.html: Responsive interactive video presentation and client demo portal.
- ecowildlife-demo.mp4: Audio-synced screen recording and live call interaction.
- workflow.png: Telephony state machine and routing logic.
